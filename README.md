# 常见百化分速记

行测资料分析「百化分」速记与刷题工具。纯静态单页应用，无需构建、无需依赖，双击 `index.html` 即可使用。

## 功能

- **速记表**：分母 2~20 的 `1/n` 常用分数与百分数对照，另收录高频衍生分数（如 2/7、5/12、3/16 等），支持按分母 / 按百分数两种排序。
- **刷题练习**：
  - 两个出题方向：百分数 → 分数、分数 → 百分数
  - 三档难度：简单（分母 2~8）、中等（分母 9~15）、困难（分母 16~20 + 衍生分数）
  - 干扰项自动选取数值最接近的分数，专治易混淆
  - 答完即时反馈对错并显示正确对照
- **计时挑战**：50 题限时连答，实时显示用时，结束后给出用时、正确率与错题回顾。

## 使用

直接用浏览器打开 `index.html`，或启动任意静态服务器：

```bash
# 例如使用 Node
npx serve .
```

## 安装为应用（PWA）

线上版 <https://gxio168.github.io/percent-fraction-trainer/> 支持安装：

1. 用 Edge / Chrome 打开上面的地址
2. 点击地址栏右侧的**安装**图标（⊕），或在页面菜单中选择「应用 → 安装」
3. 之后可从桌面图标直接启动独立窗口，**完全离线可用**（由 `sw.js` 缓存实现，更新版本后自动刷新）

> 本地双击 `index.html` 的用法不依赖网络，也不会注册 Service Worker。

## 数据来源

所有对照关系为数学计算结果（`分子 ÷ 分母`），百分数展示精度遵循行测惯用记法（精确值如 12.5%、6.25%，近似值保留一位小数如 14.3%）。
